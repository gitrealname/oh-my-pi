## Native addon situation

### Why baseline fails to load Process
- `index.js` `detectAvx2Support()` on Windows uses PowerShell:
  `[System.Runtime.Intrinsics.X86.Avx2]::IsSupported`
- **Windows PowerShell 5** (default) throws `Unable to find type` — returns null
- `runCommand()` returns null → `detectAvx2Support()` returns `false`
- `resolveCpuVariant()` returns `"baseline"`
- Old Apr 26 baseline binary loaded → missing `Process` class

### Hardware
- i7-4770K — **does support AVX2** (Haswell)
- `.node` files are gitignored; must be built locally per-machine
- `modern` binary: rebuilt May 1 15:32 ✅ has `Process`
- `baseline` binary: Apr 26 22:53 ❌ missing `Process`, locked by running omp

### Workaround (if baseline still locked)
```
PI_NATIVE_VARIANT=modern bun test ...
```
or set permanently in shell:
```powershell
$env:PI_NATIVE_VARIANT = "modern"
```
